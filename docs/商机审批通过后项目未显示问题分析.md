# 商机审批通过后安全服务中看不到项目 - 问题分析

## 问题描述

商机【好日子烟草2026年第一季度攻防演练服务】审批已全部通过，部门分配为安全技术服务部 15,000 元。用户选择了安全技术服务部，但在安全服务/项目管理中看不到对应项目。

## 根本原因分析

### 1. 流程设计：商机审批通过 ≠ 项目创建

根据代码流程（`CrmBusinessServiceImpl.java`）：

```
商机审批通过 (updateBusinessAuditStatus)
    ↓
仅执行：创建钉钉群 + 发送通知
    ↓
通知内容："请负责人在系统中选择下一步：提前投入 或 等待签订合同"
    ↓
【此时不会创建项目】注释明确："项目由前端选择创建路径"
```

**项目创建** 只在以下两种情况下触发：

| 触发条件 | 代码位置 | 说明 |
|---------|---------|------|
| **提前投入审批通过** | `updateEarlyInvestmentAuditStatus` → `createProjectInternally` | 负责人需在商机详情页点击「提前投入」，填写表单并提交审批 |
| **合同签订** | `CrmContractServiceImpl` → `createProjectFromBusiness` | 负责人需在商机详情页点击「签合同」，创建合同并审批通过 |

### 2. 概念混淆：「选择安全技术服务部」vs「选择下一步」

- **部门预计分配（安全技术服务部：15,000 元）**：这是商机阶段的预算分配，仅用于展示和后续合同/项目预算带入，**不是**操作选择。
- **下一步选择**：必须在系统中明确执行：
  - **提前投入**：进入商机详情页 → 点击「提前投入」按钮 → 填写工作内容、投入人员等 → 提交审批
  - **等待签订合同**：进入商机详情页 → 点击「签合同」按钮 → 创建合同 → 合同审批通过

### 3. 正确操作流程

```
商机审批通过
    ↓
进入商机详情页（CRM → 商机管理 → 点击「好日子烟草...」）
    ↓
选择其一执行：
  A) 点击「提前投入」→ 填写表单 → 提交 → 等待审批通过 → 项目自动创建
  B) 点击「签合同」→ 创建合同 → 合同审批通过 → 项目自动创建
    ↓
项目创建后，在 project、project_dept_service 表中生成记录
    ↓
安全服务页面（getDeptServicePage, deptType=1）可查询到该项目
```

## 建议操作（针对好日子烟草商机）

1. 打开 **CRM → 商机管理**，找到「好日子烟草2026年第一季度攻防演练服务」
2. 进入商机详情页
3. 若需立即启动项目：点击 **「提前投入」**，填写工作内容、投入人员等，提交审批
4. 若等合同签订后再启动：点击 **「签合同」**，创建合同并走审批流程
5. 审批通过后，项目会自动创建，安全技术服务部即可在「安全服务」中看到该项目

## 可选优化建议（产品/UX）

若希望减少用户困惑，可考虑：

1. **钉钉通知增强**：在审批通过通知中增加「提前投入」「签合同」的跳转链接，直接打开商机详情页
2. **商机列表/详情提示**：对已审批通过但未创建项目的商机，增加醒目提示「请选择：提前投入 或 签合同」
3. **流程说明文档**：在系统帮助中明确说明「商机审批通过后需主动发起提前投入或签合同，项目才会创建」
